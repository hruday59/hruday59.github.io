Flat root folder structure (no subfolders):

## GitHub Pages Upload Steps
1. Extract `hruday59.github.io-v3.zip`.
2. Upload `index.html`, `styles.css`, and `script.js` directly into the root of your `hruday59.github.io` repository (not inside a nested folder).
3. In GitHub repository Settings -> Pages, ensure the source branch is set to root (`/ (root)`).
